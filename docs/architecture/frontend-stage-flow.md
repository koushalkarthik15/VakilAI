# Frontend Stage Flow

Vakil AI guides the user through a linear, non-conversational pipeline. Each stage is responsible for rendering specific outputs generated by the deterministic and AI orchestration systems.

```mermaid
stateDiagram-v2
    [*] --> Landing
    
    Landing --> Upload : "User selects PDF"
    
    Upload --> Understand : "API Analysis Begins"
    note right of Understand
        Renders plain-language summary of document,
        parties involved, and core obligations.
    end note
    
    Understand --> Flag
    note right of Flag
        Renders risk highlights, anomalies, and
        potential legal inconsistencies.
    end note
    
    Flag --> Compare
    note right of Compare
        Renders side-by-side comparison of document
        clauses vs baseline Legal KB rules.
    end note
    
    Compare --> Act
    note right of Act
        Renders mapped, concrete next steps, required
        documents, and verified government portals.
    end note
    
    Act --> Prepare : "User clicks Generate Briefing Sheet"
    note right of Prepare
        (Optional) Renders an AI-generated narrative
        Attorney Preparation Sheet based on findings.
    end note
```

## State Management
- **Zustand Store**: The active stage and all associated contextual data (`UnderstandingContext`, `AnalysisContext`, `ComparisonContext`, `ActionContext`, `PrepareContext`) are managed in an ephemeral client-side Zustand store.
- **Session Isolation**: Uploading a new document immediately clears all previous state, ensuring zero cross-contamination between document reviews.
