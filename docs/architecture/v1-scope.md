# Scope (V1 vs Post-V1)

Vakil AI strictly adheres to a limited V1 scope to ensure the quality, safety, and traceability of its legal analysis. The following table differentiates what is fully supported in the current implementation versus features deferred for future versions.

| Category | V1 (Current Implementation) | Post-V1 (Deferred/Future) |
| :--- | :--- | :--- |
| **Document Types** | Rental / Lease Agreements<br>Freelancer / Service Agreements | Employment Agreements<br>Non-Disclosure Agreements (NDAs)<br>Power of Attorney, etc. |
| **Input Formats** | PDF (Text-extractable only) | Scanned PDFs (OCR)<br>Word Documents (.docx)<br>Images (.png, .jpeg) |
| **Languages** | English<br>Telugu<br>Hindi | Other regional languages (Tamil, Marathi, etc.) |
| **Jurisdiction** | Telangana Law<br>Applicable Central Indian Law | Other Indian state laws<br>International jurisdictions |
| **Features** | Deterministic Classification<br>Document Understanding (Summary/Parties)<br>Risk Flagging<br>Legal Rule Comparison<br>Action Mapping<br>Optional Attorney Briefing Generation | Multi-document comparison<br>Unrestricted / General Legal Chatbot<br>Automated form filing / Legal escalation |

## Explicit Non-Goals
- **Replacing Lawyers**: Vakil AI is explicitly designed as a *preparation tool*, not a replacement for qualified legal counsel.
- **Autonomous Filing**: The system will not file complaints, send legal notices, or execute binding decisions on behalf of the user.
